# Energy Markets — Aarhus University

Course materials for Energy Markets (5 ECTS), Bachelor's in Economics
and Business Administration, 5th-semester elective, Aarhus BSS.

**Instructors**
- Christian Montes Schütte (cms@econ.au.dk)
- Simon Søndergaard Johansen (ssj@econ.au.dk)

## What's in this repo
- `data/` — datasets used in the lecture notebooks
- `notebooks/` — Jupyter / Colab notebooks for hands-on sessions
- `slides/` — (optional) compiled lecture decks

## How to run the notebooks
All notebooks are designed to run in Google Colab. Open any notebook
and click the "Open in Colab" badge at the top, or paste its GitHub
URL into https://colab.research.google.com/github/.
